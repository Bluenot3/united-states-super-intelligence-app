# Cinematic impact upgrade

The authorized job is a substantial visual upgrade of the existing impact experience, using the original explorer's dimensional graphics as a quality reference. Counts, dates, four shared filters, exact tables, source disclosure and exports remain canonical.

## Scene contract

- React owns data, controls and inspection. One raw WebGL student-field renderer renders every selected record joined by the date cursor, using two draws for each mark's halo and core; no external dependency or paid service. A separate Canvas2D overlay owns projected axes, reference planes, cohort paths and inspection. If WebGL initialization fails or context is lost, that overlay draws the same exact point set as a Canvas2D fallback.
- GPU attributes are source index, origin XYZ, target XYZ, cohort RGB and transition delay. Uniforms are transition progress, yaw, pitch, zoom, aspect and DPR. Uploaded geometry changes only on dataset/filter/date/layout changes. No fabricated records or outcome-event timestamps.
- Time layout: X = exact enrollment date, Y = eventual stage, Z = enrollment year lane. Cohort layout: radius = cohort year, angle = recorded day, height = eventual stage; within-day jitter is schematic. Stage layout: height = eventual stage, angle = before score, radius = enrollment year; the helix is schematic. Learning layout: X = before score, Y = after score, Z = cohort year. All scores use 0–100.
- Coordinates are normalized world values transformed by one shared camera function in GPU and CPU. Projected labels, picking and the fallback use that same transform. Morphing has a 1.2-second clock; geometry ends exactly at its target. Glow changes mark appearance, not counts or coordinates. Camera orbit reveals separate year layers, never changes data.
- Mouse drag or the explicit orbit button rotates. Phone scrolling remains native unless orbit mode is enabled. Reset, rotate and zoom controls work with touch and keyboard. A record inspector provides exact date, year, stage and scores. No permissions or sensors.
- URL date/layout and filters remain authoritative. A bounded camera tuple is shareable; inspection stays local. Invalid camera state uses the scene's default pose.
- Student-field DPR is capped at 1.5 desktop / 1.25 phone. Its context is scoped to the impact route. A gentle auto orbit starts by default when motion is allowed, with an explicit pause control and `orbit=0` opt-out. Rendering runs during a morph or enabled orbit, pauses offscreen or hidden, and becomes static in Still mode or OS reduced motion. Stopping motion snapshots the live camera for links and downloads. GPU buffers/programs are deleted on disposal; context restore reinitializes once.
- Exact tables and record navigation remain the accessibility path. No tooltip-only essential information. Focus targets >=44px; small screens keep the full graphic width and stack the secondary controls.
- QA: exact 34,300 / 24,470 marks; four layouts and finite projected geometry; drag/reset/zoom; inspection alignment; no page overflow; reduced motion; hidden/offscreen pause; WebGL-disabled fallback; context loss/restore; existing replay, filters, tables and aggregate export regression.

## Parallel visual layers

The chronology uses measured cohort ribbons, aligned seasonal curves and exact daily-arrival stems, with pointer/tap scrubbing and three replay speeds. The atlas uses track → tier → hosting ribbons, dimensional score-bin surfaces, isometric hosting columns, a jurisdiction skyline and site glyph/profile fields. Both use native SVG/CSS, exact tables, consistent cohort semantics and motion guards. The existing strand field and analytical ledger remain intact.

Outcome terrain has a separate renderer and Canvas2D overlay. Every eligible record enters one exact 50 × 50 bin. A Gaussian kernel (σ 1.35 cells) renormalizes at source boundaries to conserve mass, then height is normalized to the filtered peak. The three pair domains retain negative gains and the full deployment-time range; deployment timing excludes records below S2. The 12 × 6 domain plane uses perspective, directional lighting and density contours, with finite 1.1-second morphs. Exact bin and neighborhood readouts distinguish integer counts from fractional smoothed density. All four filters apply across the full selected period, independently of the enrollment date cursor. The pair is validated and restored through `terrain`; all existing query parameters and hashes are preserved.
